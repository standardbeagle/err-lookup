# docs/

Current, durable reference for err-lookup: the v2 spec (`rebuild-spec.md`, which code cites by section),
search-engine and MCP-registry runbooks, the corpus lists the scan reads, and dated model, prompt and
isolation measurements that configs and code cite as the reason for a setting.

The website (errors.standardbeagle.com) lives in `site/`, not here.

Plans and in-flight work are not kept here. A plan that a tracked task cites is committed under
`docs/plans/` while the task is open, and removed once the work lands.
