# Windows Exit Codes

*This article is under development.*

## Common Codes

| Code | Hex | Meaning |
|------|-----|---------|
| 0 | 0x0 | Success |
| 1 | 0x1 | Incorrect function |
| 2 | 0x2 | File not found |
| 3 | 0x3 | Path not found |
| 5 | 0x5 | Access denied |
